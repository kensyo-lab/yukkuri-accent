# ゆっくりアクセント辞書

[![最新版](https://img.shields.io/github/v/release/kensyo-lab/yukkuri-accent?label=%E6%9C%80%E6%96%B0%E7%89%88)](https://github.com/kensyo-lab/yukkuri-accent/releases/latest)

YMM4 が出す AquesTalk（ゆっくりボイス）の読み記号列を、作者さん自身の辞書で自動補正するツールです。使うほど、その人のクセを覚えていきます。

## 使用法（3ステップ）
1. 入れる：[最新のリリース](https://github.com/kensyo-lab/yukkuri-accent/releases/latest)の Assets から `yukkuri-accent-vX.X.X-windows.zip` をダウンロードして展開し、`yukkuri-accent.exe` を開きます（止められたときは「[ダウンロードと起動](#ダウンロードと起動)」）

2. 直す：YMM4 でセリフの読みをコピーして、このツールの画面に戻ります。自動で辞書を当てて直し、結果をクリップボードに入れます
3. 戻す：YMM4 に戻って貼り付けます

直したアクセントを辞書に入れておくと、次から同じ所は自動で直ります。試聴（AquesTalkPlayer）・台本のまとめチェック・辞書の競合チェックなどは、下の「[詳しい使い方](#詳しい使い方)」にあります。

---

##このツールの考え方：YMM4 の読みを全部自動で正解にすることは目指しません。人が確かめるべき所だけを、いちばん早く見つけられるようにすることを目指しています。辞書で直せる所は辞書で直し、残りは「未確認」「誤爆注意」として目に見えるようにして、耳で確かめる時間を、確かめるべき所だけに使えるようにします。

> 困ったときは [よくある質問（FAQ）](FAQ.md) をご覧ください。「YMM4 に貼ってもアクセントが効かない」「試聴が平坦に聞こえる」など、つまずきやすい所の解決方法をまとめています。

## ダウンロードと起動

### かんたんな方法（Windows・Pythonは不要）
1. [最新のリリース](https://github.com/kensyo-lab/yukkuri-accent/releases/latest)を開き、下の Assets にある `yukkuri-accent-vX.X-windows.zip` をダウンロードします（「Source code」の方には .exe が入っていません。また、このページ上部の緑の「Code」ボタンから落とせるのもソースコードです）

2. 好きなフォルダに展開します（例: `C:\Users\（ユーザー名）\yukkuri-accent`）。「Program Files」の中や、OneDrive などの同期フォルダは避けてください。OneDrive のバックアップがオンだと「デスクトップ」「ドキュメント」も OneDrive の中になります（こうした場所で起動すると、メッセージ欄で知らせます）
3. `yukkuri-accent.exe` をダブルクリックして起動します

初回起動時に、同じフォルダに `accent_dict.json`（空の辞書）・`numbers.json`（数字の読み表）・`settings.json`（設定）と、`backup` フォルダ（辞書のバックアップ）が作られます。
新しい版に入れ替えるときは、ユーザーデータの `accent_dict.json`（辞書）・`numbers.json`（数字の読み表）・`settings.json`（設定）・`backup` フォルダ（辞書のバックアップ）はそのまま残し、それ以外の配布ファイル（`yukkuri-accent.exe`・README・FAQ・CHANGELOG・`dictionaries` など）は、新しい版のもので置き換えてください。
（.exe だけを差し替えても動きますが、README・FAQ・作者の辞書が古いまま残ってしまいます）

> 「WindowsによってPCが保護されました」と出たら
> 個人が作った署名のないソフトなので、初回に表示することがあります。「詳細情報」→「実行」で起動できます。
> まれに、ウイルス対策ソフトが誤って検知することもあります（PyInstallerで作ったソフトでよく起きる現象です）。
> 気になる場合は、下の「Pythonで動かす方法」を使ってください。中身はすべてこのリポジトリで公開しています。
>
> 「スマート アプリ コントロールが…ブロックしました」と出たら（Windows 11）
> 署名のない exe を止める保護機能で、「実行」のボタンがありません。下の「Pythonで動かす方法」を使ってください（署名付きの Python で動かすので止められません。機能は同じです）。詳しくは [FAQ](FAQ.md) を見てください。

### Pythonで動かす方法
> Python で動かす場合は、Windows 版の zip ではなく、GitHub の「Source code (zip)」またはリポジトリ本体を取得してください。（Windows 版の zip には .exe しか入っていません）

Python 3.8以降（tkinter付き）が入っていれば、追加のインストールは要りません。

1. [python.org](https://www.python.org/downloads/) から Python を入れます（途中の「tcl/tk and IDLE」はチェックが入ったまま。tkinter のためです）

2. [最新のリリース](https://github.com/kensyo-lab/yukkuri-accent/releases/latest)の Assets にある「Source code (zip)」をダウンロードして、好きな場所に展開します
3. exe 版から乗り換えるときは、`accent_dict.json`・`numbers.json`・`settings.json`・`backup` フォルダを、展開したフォルダへコピーします（形式は同じなので、そのまま使えます）
4. `yukkuri-accent.pyw` をダブルクリックします
`yukkuri-accent.pyw` をダブルクリックすると、コンソール画面を出さずに起動します。コマンドで起動する場合は次のとおりです。

```
python accent_app.py
```

## 詳しい使い方

### 1. 変換タブ
1. YMM4で台詞の読み（初期状態）をコピーします

2. このツールの画面に切り替えます（クリックや Alt+Tab）。コピーした読みを自動で貼り付けて変換します
3. 結果が自動でクリップボードに入るので、YMM4に戻ってそのまま貼り付けます

- ボタンを押さなくても変換します（「戻ってきたら自動で貼り付けて変換」がオンのとき。最初からオンです）。変換タブを開いているときに、新しくコピーされた読みがあれば動きます

  - 漢字を含む文章（ふつうの文章）や、このツールが自分でコピーした結果には反応しません
  - 変換結果を手直ししている途中は、自動では変換しません（手直しを消さないため）。メッセージ欄で知らせるので、［貼り付けて変換］（Ctrl+Shift+V）を押してください
  - 自分のタイミングで変換したいときは、チェックを外して［貼り付けて変換］を使ってください

- 黄色は辞書で置き換えた所、赤はエラー、橙は注意です。下のリストをクリックすると、その場所を選択します

- ウィンドウ下のメッセージ欄に、いま起きたことと次にすることを表示します。大事さで色が変わります

  - 赤：このままでは YMM4 で正しく読まれない（エラーが残っている、プリセットが棒読み、試聴の失敗 など）
  - 橙：ツールが文字を書き換えた、または確かめてほしい所がある（記号の自動修正、注意 など）
  - 灰：済んだことのお知らせ（コピーしました、再生中 など）
- 記号は半角でも全角でも入力できます。`'` `/` `_` `,` `+` `;` は半角に、`、` `。` `？` は全角にそろえます。`_` の直後はカタカナにします

- この直しは打ったそばから行います（YMM4 は全角の `’` `＿` などを記号として受け付けないため）。たとえば変換結果の欄で `’` を打つと、すぐに `'` になり、メッセージ欄に「’→'」のように何を直したか表示します。Ctrl+Z で打った文字ごと元に戻せます


#### なぜこうなったかを見る（使われた辞書・未確認の文節）
変換結果の下の行に、今回の変換で何が起きたかを出します（例：`辞書 6か所（5項目・文脈付き1・誤爆注意1） 未確認 4文節`）。

- 文節の色：変換結果の文節を、何が起きたかで色分けします。「正しいかどうか」ではなく「何が起きたか」の印です（辞書が当たった所でも、誤爆していることはあります）

  - 黄：辞書で置き換えた所
  - 黄＋赤い下線：誤爆しやすい項目（助詞だけ・短い語 など）が当たった文節。本当にそこで当たってよいか確かめてください
  - 淡い青（未確認）：辞書も手直しも入っていない、YMM4 の読みそのままの文節。耳で確かめたい所です
  - 淡い緑（手直し）：変換結果の欄で、手で直した文節
  - 色が多すぎると感じたら、設定タブで消せます
- ［次の未確認へ ▶］（F11。前へは Shift+F11）：未確認と誤爆注意の文節を、順に選びます。選んだまま ［▶ 試聴］（F5）を押すと、その文節だけを聞けます。

- 聞いて良ければ、文節を右クリック →「この文節を確認済みにする」。色が消え、［次の未確認へ］でも飛ばします。（もう一度［変換］すると、確認済みの印は消えます）

- 黄色い所をクリックすると、どの辞書の項目が当たったのかをメッセージ欄に出します。右クリックのメニューにも「辞書：たんさき →たんさ'き」のように出て、「辞書タブでこの項目を開く」で、その行に飛べます

- ［使われた辞書…］：今回当たった項目を、当たった回数・条件・誤爆の注意と一緒に一覧にします。行を選ぶと変換結果の当たった所を選び、もう一度選ぶと次の所へ移ります。思わぬ所で当たっている項目（たとえば「わ」が「わたる」の頭にも当たっている）を見つけるのに使ってください


#### 台本をまとめてチェックする（台本の一覧）
動画1本分の読みを、まとめて校正できます。

1. ①に、YMM4 の読みを”1行1台詞”で貼り付けるか、［ファイルを開く…］で読みのテキストファイル（UTF-8 か Shift_JIS）を読み込みます

2. ［変換］すると、全部の台詞を一度に直します
3. ［台本の一覧…］で、台詞ごとの状態を一覧にします（例：`全38台詞 辞書 143か所 エラー 0 要確認 12台詞（未確認 27文節・誤爆注意 3文節） 済 26台詞`）
   - 状態：エラー（赤）／要確認（橙：未確認・誤爆注意・エラーが残っている）／済（緑）
   - 行を選ぶと、変換結果のその行を選びます。そのまま［試聴］で、その台詞だけを聞けます。
   - ［次の要確認の台詞へ ▶］で、まだ見ていない台詞へ順に移ります。台詞の中の文節は［次の未確認へ］（F11）で順に選べます。
   - ［この台詞をコピー］で、その行だけをクリップボードに入れて、YMM4 のその台詞に貼り付けます。
   - 一覧は開いたままにしておくと、確認済みにしたり手直ししたりするたびに書き直されます。

#### アクセントを聞き比べる（A/B 試聴）
文節を右クリック →「アクセントを聞き比べる…」で、その文節に付けられるアクセントの形（平板・1拍目・2拍目…）を全部並べます。
- 行を選ぶと、その形ですぐ読み上げます。↑↓キーで2つの行を行き来すると、聞き比べ（A/B）になります。人の耳は、1つだけ聞くより比べた方がずっと判断しやすいです。

- 読む範囲は「その行（前後の流れごと）」か「文節だけ」を選べます。ふつうは前後の流れごとの方が、YMM4 で聞いたときに近くなります。

- 決まったら［この形を採用］で、変換結果のその文節に反映します。


#### アクセント編集（ボタンでアクセントを付ける）
［アクセント編集 ▼］ を押すと、ウィンドウが縦に広がり、変換結果を文節ごとに並べた欄が開きます。もう一度押すと閉じて、ウィンドウも元の高さに戻ります（開いたままにしておくと、次回も開いた状態で起動します）。

- 文字の上の小さなボタンを押すと、その文字にアクセント（`'`）が付き、下の変換結果の欄にすぐ反映されます

- 高低の線：文字の上に、音の高さを線で描きます（上が高い・下が低い）。アクセントで音が下がる所は赤い線です。試聴しなくても、どう読まれるかが目で確かめられます（「高低の線を表示」で消すこともできます）

  - 線の点はつまんで上下に動かせます。 離した所の高さになるように、アクセントの位置を自動で置き直します（今の形から変わる所がいちばん少ない置き方を選びます）。点をクリックするだけなら、その点の高低を入れ替えます
    - 例：`ぶ'んしょう`（高低低低）の「しょ」を上へ → `ぶんしょ'う`（低高高低）／最後の点を上へ → 平板
  - 線は、東京式アクセントの基本の形（平板＝低高高…、アクセントの所まで高くてその後は低い）で描いています。AquesTalk の実際の抑揚とは、細かい所が違うことがあります
- 文節を右クリックすると（アクセント編集の欄でも、変換結果の欄でも）、その文節だけを操作できます。メニューには、戻した後の形も表示します

  - この文節を変換直後に戻す：アクセントを動かしすぎた・区切りを変えたら変になった、というときに、その文節だけを［変換］した直後の形に戻します。区切りを足したり消したりした文節も、まとめて元に戻ります
  - この文節を辞書適用前に戻す：辞書で置き換える前の、YMM4 の読みそのままの形に戻します（辞書の置き換えが合っていないときに）
  - この文節を辞書に登録…：辞書の追加画面が、YMM4側＝辞書を当てる前の形、置き換え後＝今の文節、が入った状態で開きます。確かめて OK を押せば、その場で辞書に入ります（同じ項目があれば、上書きの前に確かめてバックアップします。誤爆しやすい形なら知らせます）
  - この文節を学習候補に送る：その文節の手直しだけを、学習タブの候補に送ります。［語］［句］の候補を見比べてから登録したいときに
  - どれも Ctrl+Z で元に戻せます。気軽にいろいろ試してください
- キーボードでも操作できます（変換結果の欄で、カーソルのある文節が対象）

  - Alt＋← ／ Alt＋→：アクセントを前／後ろの文字へ動かす（端まで行くと平板、平板からは端の文字へ）
  - Alt＋↑：カーソルの前の文字にアクセントを付ける
  - Alt＋↓：アクセントを外す（平板）
- 1つの文節に付くアクセントは1か所だけです。別の文字のボタンを押すと付け替わり、赤いボタンをもう一度押すと外れます（平板）

- `ー` `っ` `ん` や記号には、アクセントを置けないのでボタンがありません

- `きゃ` `じゅ` `しょ` などは、小さい文字と前の文字をまとめて1文字として扱います。`'` は `きゅ'ー` のように、そのまとまりの直後に入ります

- 無声化（`_ス` など）の文字は青で表示します

- 変換結果の欄を直接書き換えても、この欄はすぐに追従します。Ctrl+Z で元に戻せます


### 2. 学習タブ
左に「YMM4の初期出力」、右に「直した後の完成形」を貼って ［差分から候補を出す］ を押します。
候補が一覧で出るので、チェックを確認して ［チェックしたものを辞書に登録］ を押してください。

- ［句］は句のまとまり、［語］は助詞を外した単語です（［語］のほうが他の文にも効きます）

- ［数字］は参考表示です。数字の読み方は読み表で決めるので、初めからチェックを外してあります

- 「句頭のみ」を付けると、句の頭でだけ置き換えます（`さき` が `たんさき` の中で誤って置き換わるのを防ぎます）

- 変換タブで手直ししたら、［手直しを辞書の候補に送る →］ で、手で直した文節（淡い緑）だけをまとめて学習タブの候補にできます。直すたびに「辞書に入れますか？」と聞くことはしません。押さなければ、その場限りの手直しのままです


### 3. 辞書タブ
検索・追加・編集・削除ができます。見出しをクリックすると並べ替えられます（使用回数順も可）。
- 使用回数は、その項目が当たった台詞の数です。同じ台詞を何度変換し直しても1回と数えます。

- ［統計…］：登録数・今月追加・使用回数の合計・文脈付き／句頭のみ／誤爆しやすい項目の数と、「よく使われた項目」「一度も使われていない項目」の一覧。一度も使われていない項目は、辞書の整理に使えます

- ［競合を調べる…］（辞書の DRC）：項目ごとに「その項目が当たるはずの、いちばん短い文」を作り、いまの辞書で実際に変換して確かめます。次のものを見つけます

  - 効かない：ほかの項目に隠れて、条件どおりの文でも使われない項目（例：条件なしの `はしを` に隠れた、文脈付きの `はし`）
  - 無駄・要確認：無くても結果が同じ項目（短い項目で足りている など）・何も変えない項目・置き換え後にエラーがある項目
  - お知らせ：同じ YMM4側に条件違いの項目が多いもの
  - 優先順位の規則を別に書き直して判定するのではなく、変換そのものを使うので、判定と本番の結果がずれません
［他の辞書を取り込む］ で他の作者さんの辞書を取り込めます。すでにある項目は、自分の辞書を優先して残します。

文脈付きの項目（前後の条件）：項目に「直前が○○のときだけ」「直後が○○のときだけ」という条件を付けられます。は／わ や、同じ読みの別の言葉（例：`はし` が「橋」か「箸」か）の誤爆よけに効きます。
- 例：`はし` → `はし'`（条件：直後が「をわたる」）と、条件なしの `はし` → `は'し` を両方入れておくと、「はしを渡る」の所だけ前者が当たります

  - ※ `/` などの記号は比べるときに無視されます（「を/わたる」と入れても同じです）
- 文脈条件は、文章の意味を解析するものではありません。 前後の読み（仮名の並び）が一致した場合だけ当てる仕組みです。「橋」と「箸」を見分けているのではなく、「直後が『をわたる』なら」という読みの並びで決めています。

- 同じ YMM4側でも、条件が違えば別の項目として何個でも持てます。

- 条件は、アクセント・区切り・無声化の記号を無視して、仮名だけで比べます。句点（。）や改行はまたぎません（条件に「。」を入れると、文頭・文末の指定になります）

- どれが当たるか（優先順位）：同じ所で複数の項目が当たりうるときは、次の順で1つだけ当てます。辞書が育っても結果が変わらないよう、この順番は固定です

  1. YMM4側が長い項目（条件の有無より先に比べます。長い条件なしの項目は、短い条件付きの項目より先です）
  2. YMM4側が同じ長さなら、前後両方の条件 → 片側だけの条件 → 条件なし
  3. 同じ段なら、前後の条件に含まれる仮名の合計文字数が多い方（記号は数えません。例：直前が「たいようけい」は「たいよう」より先。「前10文字＋後1文字」と「前5文字＋後7文字」なら、合計12の後者が先）
  4. それでも同じなら、辞書の並び順（YMM4側・前・後の五十音順。登録した順番には左右されません）
- 辞書の追加・編集画面の「条件：直前が」「条件：直後が」に入れます。文節の右クリック「この文節を辞書に登録…」から開くと、前後の文節をボタン一つで条件に入れられます

- 辞書タブの「条件（前／後）」の列で確かめられます。条件の付いた項目は当たる所が限られるので、誤爆の印は付けません


誤爆しやすい項目に印を付けます。 辞書は文章のどこでも当たるので、短い語（2拍以下）・助詞だけの項目・「わ」を含む短い語・助詞と同じ文字で始まる／終わる短い語は、ほかの言葉の中でも置き換わってしまうことがあります。こうした項目は「注意」の列に理由を出して橙色で表示し、「誤爆しやすい項目だけ」で絞り込めます。「句頭のみ」や前後の条件を付けると、当たる所が限られるので、誤爆しにくくなります。

辞書は自動でバックアップします。 起動したときと、削除・取り込み・バックアップから戻す前に、`backup` フォルダへ写します（中身が前回と同じときは写しません。新しい20個まで残します）。
間違えて消したときは ［バックアップから戻す…］ で、日時と件数を見ながら前の状態に戻せます。各時点ごとに「戻すと：＋3 －1 変更2」のように今との違いを表示し、選ぶと、増える・消える・変わる項目を一覧で確かめられます。戻す前の辞書もバックアップに残るので、戻しすぎても大丈夫です。
辞書ファイルが壊れて読めないときは、壊れたファイルを `accent_dict_broken_（日時）.json` という名前で残して起動し、メッセージ欄で知らせます。

### 4. 試聴（Windowsのみ）
変換結果を、YMM4に貼る前にその場で聞いて確かめられます。読み上げには、株式会社アクエストの AquesTalkPlayer を使います。

1. [AquesTalkPlayer](https://www.a-quest.com/products/aquestalkplayer.html) を公式サイトから入手して、好きな場所に展開します。

2. このツールの 設定タブ で、`AquesTalkPlayer.exe` の場所を指定します（［参照…］で選べます）
3. 変換タブの「声（プリセット）」で声を選び、［▶ 試聴］ を押します。［■ 停止］ で止まります。

- 音量：［▼］［▲］で 10% ずつ、0%〜150% の間で変えられます。鳴っている途中で変えると、新しい音量で最初から鳴らし直します。

- ［消音］（F9）：押すとすぐに音が止まり、もう一度押すと元の音量に戻ります。鳴っている途中だった試聴は、最初から鳴らし直します。

- 音量と消音は、このツールの試聴だけに効きます（パソコン全体の音量や YMM4 の音量は変わりません）。次に起動したときも引き継ぎます。


- 変換結果の欄で範囲を選択していればその部分を、選択していなければ全体を読み上げます。欄で手直しした内容も、そのまま読み上げに反映されます。

- 再生中は、実際に読み上げている記号列を下のメッセージ欄に表示します。

- 声は AquesTalkPlayer のプリセット名で選びます。プルダウンには、AquesTalkPlayer のプリセット（`AquesTalkPlayer.exe` と同じフォルダの `AquesTalkPlayer.preset`）が自動で並びます。プルダウンを開くたびに読み直すので、AquesTalkPlayer で作ったプリセットもすぐに選べます。欄に名前を直接入力することもできます

- 棒読みがオンのプリセットを選ぶと、「アクセントが効かない」ことをメッセージ欄で知らせます

- 自分のキャラクター用の声も使えます。 AquesTalkPlayer で声の種類・速さ・高さなどを調整してプリセットとして保存し、その名前を「声（プリセット）」に入力してください。一度再生できた名前は候補に残ります

- 最後に使った声と AquesTalkPlayer の場所は `settings.json` に保存され、次回も引き継がれます

- AquesTalkPlayer がエラーになったとき（プリセット名が無い、記号列にエラーが残っている など）は、その旨を表示します

- AquesTalkPlayer は Windows 用のソフトなので、Windows 以外では試聴ボタンは押せません

- ［AquesTalkPlayer を開く］（変換タブ・設定タブ）で、AquesTalkPlayer をそのまま起動できます。声の調整やプリセットの作成に使ってください

- アクセント（`'`）が効かず平坦に聞こえるときは、プリセットの「棒読み」がオンになっています（棒読みがオンだと `'` が無視されます）。最初からある「まりさ」「れいむ」は棒読みがオンで、［Set］で変更しても次に起動したとき元に戻ってしまいます。次の手順で自分用のプリセットを作ってください

  1. ［AquesTalkPlayer を開く］で開き、「まりさ」を選ぶ
  2. 「棒読み」のチェックを外す（YMM4 の「ゆっくり魔理沙」に近づけるなら、声種「AquesTalk1 f2」・話速 110 が目安）
  3. ［Add］を押して、新しい名前（例: `まりさ抑揚`）で保存する
  4. このツールの「声（プリセット）」欄にその名前を入れて試聴する

## 数字の扱い
YMM4は数字を `<NUMK COUNTER="にち" VAL="6.39">` のようなタグで出し、その部分は前後から切り離して読まれます。
このツールはタグを仮名に展開して、前後とつなげて読める形にします。

| YMM4の出力 | 変換後 |
|---|---|
| `<NUMK COUNTER="にち" VAL="6.39">` | `ろ'くてん/さんきゅ'ーにち` |
| `<NUMK COUNTER="ねん" VAL="248">` | `にひゃくよ'んじゅー/hach'ねん` |
| `<NUMK COUNTER="きろめーとる" VAL="2377">` | `にせ'ん/さ'んびゃく/なな'じゅー/ななきろめ'ーとる` |
| `<NUMK COUNTER="ど" VAL="17.16">` | `じゅーな'なてん/いちろく'ど` |
| `だい<NUMK COUNTER="しょう" VAL="3">` | `だ'い/さ'んしょー` |

YMM4側のクセもいくつか後始末します。
- `5,906.4` が `<NUMK VAL="5">,<NUMK VAL="906.4" …>` に割れる → つなぎ直します

- `km/s` → `…きろめーとる>ず`、`m/s²` → `…めーとる>ず/`、`30億km` → `…おく>/くむ` と化ける → 単位の読みに直します

- `×10⁶` は指数がYMM4で消えるため、`じゅ'ーの/〓じょー` と出してエラー表示します。〓 を「ろく」などに書き換えてください

- `−230℃` の「−」もYMM4で消えます。台本には「マイナス」と書くのが確実です


読み方（アクセント・区切り・助数詞ごとの特別な読み・無声化）は、すべて `numbers.json` で変えられます。
辞書タブの ［数字の読み表を開く］ で編集し、［読み表を再読み込み］ で反映します。

## 育てた辞書を守る仕組み
辞書は使うほど育つ、このツールでいちばん大事なデータです。消えたり壊れたりしないよう、次の仕組みがあります。

- 自動バックアップ：起動したとき、項目を消す・上書きする・取り込む・戻す前に、`backup` フォルダへ自動で写します（新しい20個。前回と同じなら写しません）

- 節目のバックアップ（消えない）：新しい版を初めて起動する前と各月の最初の辞書を、`backup/keep` フォルダに残します。こちらは古い順に消えません。版を上げて何かおかしくなっても、上げる前の辞書に戻せます

- バックアップから戻す：辞書タブの［バックアップから戻す…］で、時点を選ぶと「戻すと何が増え、何が消えるか」を確かめてから戻せます（［保管］が節目のバックアップです）。戻す前の辞書も、バックアップに残します

- 壊れた辞書でも起動できる：辞書ファイルが壊れていたら、名前を変えて残し、空の辞書で起動します。そこからバックアップに戻せます

- 形式の互換：古い版（v0.2〜）の辞書は、そのまま読めます。条件（文脈）を使わない辞書は、古い形式のまま保存するので、古い版でも開けます

- 知らない情報は消さない：将来の版で辞書に情報が増えても、この版で開いて保存したときに、その情報を消さずに残します（新しい版で作られた辞書だと、起動時に知らせます）

- 書き出し・取り込み：［別名で書き出す…］で辞書を1つのファイルにでき、別の PC や他の作者さんとやりとりできます。［他の辞書を取り込む…］では、すでにある項目は自分の辞書を優先して残します

- 保存は安全な書き方：いったん別のファイルに書いてから置き換えるので、保存の途中で落ちても、辞書が半分だけになることはありません

- 辞書を守る仕組みは、テスト（`tests/test_dict_safety.py`）で確かめています

## 新しい版の出し方（開発者向け）
1. `accent_app.py` の `VERSION` を上げる（例: `"0.9.2"`）

2. `release-notes/v0.9.2.md` にリリースノートを書く（版の番号と同じ名前）
3. main に送る

GitHub Actions がテストを動かし、Windows 版を作って、`v0.9.2` のタグと Release を自動で作ります。

テストの動かし方：`tests/` のテストは unittest / pytest の形ではなく、assert を並べて、そのまま実行する形です（`python -m unittest` や `pytest` では「0件」と出ます）。
```
python tests/run_all.py              # 全部まとめて（どれか失敗すると終了コード 1）
python tests/test_dict_safety.py     # 1つずつ
```

## 記号の仕様
[AquesTalk 音声記号列仕様書](https://www.a-quest.com/archive/manual/siyo_onseikigou.pdf)に従って検査しています。
`/` 区切り、`,` 短いポーズ、`、` 長いポーズ、`+` 後ろが副次アクセント、`;` 次の句が高く始まる、`'` アクセント核、`_` 無声化。
「句の先頭の ー」「っっ」「っー」などの禁止並びもエラーにします。

## 分かっている限界
- 間の `,` は文の流れで変わるので、学習していません

- 同じ人でも数字の切り方は日によって揺れるので、読み表は「いちばん多い形」を既定値にしています

- 「は／わ」の区別は、語尾の `わ` を助詞とみなす簡単な方法です（`こんにちわ` などは例外扱い）
