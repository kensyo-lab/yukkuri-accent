# ゆっくりアクセント辞書

[![最新版](https://img.shields.io/github/v/release/kensyo-lab/yukkuri-accent?label=%E6%9C%80%E6%96%B0%E7%89%88)](https://github.com/kensyo-lab/yukkuri-accent/releases/latest)

YMM4が出力するAquesTalk（ゆっくりボイス）の読み記号列を、**作者さん自身の辞書**で自動補正するツールです。
直し方はプログラムには書き込まず、辞書（`accent_dict.json`）と数字の読み表（`numbers.json`）に置いています。使うほど、その人のクセを覚えていきます。

v0.3 からは、AquesTalk の開発元・株式会社アクエストの公式アプリ **AquesTalkPlayer** を使って、直した読みを**その場で試聴**できるようになりました（Windowsのみ・AquesTalkPlayer は各自で入手。詳しくは「[4. 試聴](#4-試聴windowsのみ)」）。
YMM4に貼る前に耳で確かめられるので、「直す → 聞く → また直す」がこのツールの中だけで回せます。

> **困ったときは [よくある質問（FAQ）](FAQ.md) をご覧ください。**「YMM4 に貼ってもアクセントが効かない」「試聴が平坦に聞こえる」など、つまずきやすい所の解決方法をまとめています。

## ダウンロードと起動

### かんたんな方法（Windows・Pythonは不要）
1. [最新のリリース](https://github.com/kensyo-lab/yukkuri-accent/releases/latest)を開き、下の **Assets** にある `yukkuri-accent-vX.X-windows.zip` をダウンロードします（「Source code」の方には .exe が入っていません。また、このページ上部の緑の「Code」ボタンから落とせるのもソースコードです）
2. 好きなフォルダに展開します（例: `C:\Users\（ユーザー名）\yukkuri-accent`）。「Program Files」の中や、OneDrive などの同期フォルダは避けてください。OneDrive のバックアップがオンだと「デスクトップ」「ドキュメント」も OneDrive の中になります（こうした場所で起動すると、メッセージ欄で知らせます）
3. `yukkuri-accent.exe` をダブルクリックして起動します

初回起動時に、同じフォルダに `accent_dict.json`（空の辞書）・`numbers.json`（数字の読み表）・`settings.json`（設定）と、`backup` フォルダ（辞書のバックアップ）が作られます。
新しい版に入れ替えるときは、ユーザーデータの `accent_dict.json`（辞書）・`numbers.json`（数字の読み表）・`settings.json`（設定）・`backup` フォルダ（辞書のバックアップ）はそのまま残し、それ以外の配布ファイル（`yukkuri-accent.exe`・README・FAQ・CHANGELOG・`dictionaries` など）は、新しい版のもので置き換えてください。
（.exe だけを差し替えても動きますが、README・FAQ・作者の辞書が古いまま残ってしまいます）

> **「WindowsによってPCが保護されました」と出たら**
> 個人が作った署名のないソフトなので、初回に表示されることがあります。「詳細情報」→「実行」で起動できます。
> まれに、ウイルス対策ソフトが誤って検知することもあります（PyInstallerで作ったソフトでよく起きる現象です）。
> 気になる場合は、下の「Pythonで動かす方法」を使ってください。中身はすべてこのリポジトリで公開しています。

### Pythonで動かす方法
> **Python で動かす場合は、Windows 版の zip ではなく、GitHub の「Source code (zip)」またはリポジトリ本体を取得してください。**（Windows 版の zip には .exe しか入っていません）

Python 3.8以降（tkinter付き）が入っていれば、追加のインストールは要りません。
`yukkuri-accent.pyw` をダブルクリックすると、コンソール画面を出さずに起動します。コマンドで起動する場合は次のとおりです。

```
python accent_app.py
```

## 使い方

### 1. 変換タブ
1. YMM4で台詞の読み（初期状態）をコピーします
2. **［貼り付けて変換］**（Ctrl+Shift+V）を押します
3. 結果が自動でクリップボードに入るので、そのままYMM4に貼り付けます

- 黄色は辞書で置き換えた所、赤はエラー、橙は注意です。下のリストをクリックすると、その場所を選択します
- ウィンドウ下の**メッセージ欄**に、いま起きたことと次にすることを表示します。大事さで色が変わります
  - **赤**：このままでは YMM4 で正しく読まれない（エラーが残っている、プリセットが棒読み、試聴の失敗 など）
  - **橙**：ツールが文字を書き換えた、または確かめてほしい所がある（記号の自動修正、注意 など）
  - **灰**：済んだことのお知らせ（コピーしました、再生中 など）
- 記号は半角でも全角でも入力できます。`'` `/` `_` `,` `+` `;` は半角に、`、` `。` `？` は全角にそろえます。`_` の直後はカタカナにします
- この直しは**打ったそばから**行います（YMM4 は全角の `’` `＿` などを記号として受け付けないため）。たとえば変換結果の欄で `’` を打つと、すぐに `'` になり、メッセージ欄に「’→'」のように何を直したか表示します。Ctrl+Z で打った文字ごと元に戻せます

#### アクセント編集（ボタンでアクセントを付ける）
**［アクセント編集 ▼］** を押すと、ウィンドウが縦に広がり、変換結果を文節ごとに並べた欄が開きます。もう一度押すと閉じて、ウィンドウも元の高さに戻ります（開いたままにしておくと、次回も開いた状態で起動します）。

- 文字の上の小さなボタンを押すと、その文字にアクセント（`'`）が付き、下の変換結果の欄にすぐ反映されます
- **高低の線**：文字の上に、音の高さを線で描きます（上が高い・下が低い）。アクセントで音が下がる所は赤い線です。試聴しなくても、どう読まれるかが目で確かめられます（「高低の線を表示」で消すこともできます）
  - **線の点はつまんで上下に動かせます。** 離した所の高さになるように、アクセントの位置を自動で置き直します（今の形から変わる所がいちばん少ない置き方を選びます）。点をクリックするだけなら、その点の高低を入れ替えます
    - 例：`ぶ'んしょう`（高低低低）の「しょ」を上へ → `ぶんしょ'う`（低高高低）／最後の点を上へ → 平板
  - 線は、東京式アクセントの基本の形（平板＝低高高…、アクセントの所まで高くてその後は低い）で描いています。AquesTalk の実際の抑揚とは、細かい所が違うことがあります
- **キーボードでも操作できます**（変換結果の欄で、カーソルのある文節が対象）
  - Alt＋← ／ Alt＋→：アクセントを前／後ろの文字へ動かす（端まで行くと平板、平板からは端の文字へ）
  - Alt＋↑：カーソルの前の文字にアクセントを付ける
  - Alt＋↓：アクセントを外す（平板）
- 1つの文節に付くアクセントは1か所だけです。別の文字のボタンを押すと付け替わり、赤いボタンをもう一度押すと外れます（平板）
- `ー` `っ` `ん` や記号には、アクセントを置けないのでボタンがありません
- `きゃ` `じゅ` `しょ` などは、小さい文字と前の文字をまとめて1文字として扱います。`'` は `きゅ'ー` のように、そのまとまりの直後に入ります
- 無声化（`_ス` など）の文字は青で表示します
- 変換結果の欄を直接書き換えても、この欄はすぐに追従します。Ctrl+Z で元に戻せます

### 2. 学習タブ
左に「YMM4の初期出力」、右に「直した後の完成形」を貼って **［差分から候補を出す］** を押します。
候補が一覧で出るので、チェックを確認して **［チェックしたものを辞書に登録］** を押してください。

- ［句］は句のまとまり、［語］は助詞を外した単語です（［語］のほうが他の文にも効きます）
- ［数字］は参考表示です。数字の読み方は読み表で決めるので、初めからチェックを外してあります
- 「句頭のみ」を付けると、句の頭でだけ置き換えます（`さき` が `たんさき` の中で誤って置き換わるのを防げます）
- 変換タブで手直ししたら、**［この手直しを学習タブへ送る］** でそのまま学習に回せます

### 3. 辞書タブ
検索・追加・編集・削除ができます。見出しをクリックすると並べ替えられます（使用回数順も可）。
**［他の辞書を取り込む］** で他の作者さんの辞書を取り込めます。すでにある項目は、自分の辞書を優先して残します。

**辞書は自動でバックアップします。** 起動したときと、削除・取り込み・バックアップから戻す前に、`backup` フォルダへ写します（中身が前回と同じときは写しません。新しい20個まで残します）。
間違えて消したときは **［バックアップから戻す…］** で、日時と件数を見ながら前の状態に戻せます。戻す前の辞書もバックアップに残るので、戻しすぎても大丈夫です。
辞書ファイルが壊れて読めないときは、壊れたファイルを `accent_dict_broken_（日時）.json` という名前で残して起動し、メッセージ欄で知らせます。

### 4. 試聴（Windowsのみ）
変換結果を、YMM4に貼る前にその場で聞いて確かめられます。読み上げには、株式会社アクエストの **AquesTalkPlayer** を使います。

1. [AquesTalkPlayer](https://www.a-quest.com/products/aquestalkplayer.html) を公式サイトから入手して、好きな場所に展開します
2. このツールの **設定タブ** で、`AquesTalkPlayer.exe` の場所を指定します（［参照…］で選べます）
3. 変換タブの「声（プリセット）」で声を選び、**［▶ 試聴］** を押します。**［■ 停止］** で止まります

- 変換結果の欄で範囲を選択していればその部分を、選択していなければ全体を読み上げます。欄で手直しした内容も、そのまま読み上げに反映されます
- 再生中は、実際に読み上げている記号列を下のメッセージ欄に表示します
- 声は AquesTalkPlayer のプリセット名で選びます。プルダウンには、AquesTalkPlayer のプリセット（`AquesTalkPlayer.exe` と同じフォルダの `AquesTalkPlayer.preset`）が自動で並びます。プルダウンを開くたびに読み直すので、AquesTalkPlayer で作ったプリセットもすぐに選べます。欄に名前を直接入力することもできます
- 棒読みがオンのプリセットを選ぶと、「アクセントが効かない」ことをメッセージ欄で知らせます
- **自分のキャラクター用の声も使えます。** AquesTalkPlayer で声の種類・速さ・高さなどを調整してプリセットとして保存し、その名前を「声（プリセット）」に入力してください。一度再生できた名前は候補に残ります
- 最後に使った声と AquesTalkPlayer の場所は `settings.json` に保存され、次回も引き継がれます
- AquesTalkPlayer がエラーになったとき（プリセット名が無い、記号列にエラーが残っている など）は、その旨を表示します
- AquesTalkPlayer は Windows 用のソフトなので、Windows 以外では試聴ボタンは押せません
- **［AquesTalkPlayer を開く］**（変換タブ・設定タブ）で、AquesTalkPlayer をそのまま起動できます。声の調整やプリセットの作成に使ってください
- **アクセント（`'`）が効かず平坦に聞こえるとき**は、プリセットの「棒読み」がオンになっています（棒読みがオンだと `'` が無視されます）。最初からある「まりさ」「れいむ」は棒読みがオンで、［Set］で変更しても次に起動したとき元に戻ってしまいます。次の手順で**自分用のプリセット**を作ってください
  1. ［AquesTalkPlayer を開く］で開き、「まりさ」を選ぶ
  2. 「棒読み」のチェックを外す（YMM4 の「ゆっくり魔理沙」に近づけるなら、声種「AquesTalk1 f2」・話速 110 が目安）
  3. ［Add］を押して、新しい名前（例: `まりさ抑揚`）で保存する
  4. このツールの「声（プリセット）」欄にその名前を入れて試聴する

### 5. 文字の大きさ・ショートカット（設定タブ）
- **文字の大きさ**：80%〜200% の間で 10% ずつ変えられます（［小］［標準］［大］［特大］のボタンもあります）。高解像度のモニタや、文字を大きくしたいときにどうぞ。ウィンドウも同じ割合で大きくなります
  - **Ctrl＋マウスホイール**、**Ctrl＋＋ ／ Ctrl＋－**（100%に戻すのは Ctrl＋0）でも変えられます
- **ショートカットキー**：主な操作にキーが割り当ててあり、ボタンにも（F5）のように書き添えています。設定タブの一覧で、行をダブルクリックして好きなキーに変えられます（Ctrl・Alt・Shift との組み合わせ、または F1〜F12）

| 操作 | 最初のキー |
|---|---|
| 貼り付けて変換 | Ctrl＋Shift＋V |
| 変換 | Ctrl＋Enter |
| コピー | Ctrl＋Shift＋C |
| 試聴 ／ 止める | F5 ／ F6 |
| 再チェック | F7 |
| アクセント編集を開く／閉じる | F8 |
| アクセントを前／後ろの文字へ | Alt＋← ／ Alt＋→ |
| カーソルの前の文字にアクセント ／ 外す | Alt＋↑ ／ Alt＋↓ |
| 文字を大きく ／ 小さく ／ 100%に戻す | Ctrl＋＋ ／ Ctrl＋－ ／ Ctrl＋0 |

## 数字の扱い
YMM4は数字を `<NUMK VAL=6.39 COUNTER=にち>` のようなタグで出し、その部分は前後から切り離して読まれます。
このツールはタグを仮名に展開して、前後とつなげて読める形にします。

| YMM4の出力 | 変換後 |
|---|---|
| `<NUMK VAL=6.39 COUNTER=にち>` | `ろ'くてん/さんきゅ'ーにち` |
| `<NUMK VAL=248 COUNTER=ねん>` | `にひゃくよ'んじゅー/はち'ねん` |
| `<NUMK VAL=2377 COUNTER=きろめーとる>` | `にせ'ん/さ'んびゃく/なな'じゅー/ななきろめ'ーとる` |
| `<NUMK VAL=17.16 COUNTER=ど>` | `じゅーな'なてん/いちろく'ど` |
| `だい<NUMK VAL=3 COUNTER=しょう>` | `だ'い/さ'んしょー` |

YMM4側のクセもいくつか後始末します。
- `5,906.4` が `<NUMK VAL=5>,<NUMK VAL=906.4 …>` に割れる → つなぎ直します
- `km/s` → `…きろめーとる>ず`、`m/s²` → `…めーとる>ず/`、`30億km` → `…おく>/くむ` と化ける → 単位の読みに直します
- `×10⁶` は指数がYMM4で消えるため、`じゅ'ーの/〓じょー` と出して**エラー表示**します。〓 を「ろく」などに書き換えてください
- `−230℃` の「−」もYMM4で消えます。台本には「マイナス」と書くのが確実です

読み方（アクセント・区切り・助数詞ごとの特別な読み・無声化）は、すべて `numbers.json` で変えられます。
辞書タブの **［数字の読み表を開く］** で編集し、**［読み表を再読み込み］** で反映します。

## 新しい版の出し方（開発者向け）
1. `accent_app.py` の `VERSION` を上げる（例: `"0.3"`）
2. `release-notes/v0.3.md` にリリースノートを書く
3. main に送る

## 記号の仕様
[AquesTalk 音声記号列仕様書](https://www.a-quest.com/archive/manual/siyo_onseikigou.pdf)に従って検査しています。
`/` 区切り、`,` 短いポーズ、`、` 長いポーズ、`+` 後ろが副次アクセント、`;` 次の句が高く始まる、`'` アクセント核、`_` 無声化。
「句の先頭の ー」「っっ」「っー」などの禁止並びもエラーにします。

## 分かっている限界
- 間の `,` は文の流れで変わるので、学習していません
- 同じ人でも数字の区切り方は日によって揺れるので、読み表は「いちばん多い形」を既定値にしています
- 「は／わ」の区別は、語尾の `わ` を助詞とみなす簡単な方法です（`こんにちわ` などは例外扱い）
