## 変更
- **高低（ピッチ）の線**：アクセント編集の欄で、文字の上に音の高さを線で描くようにしました。上が高く下が低く、アクセントで音が下がる所は赤い線です。試聴しなくても、付けたアクセントでどう読まれるかを目で確かめられます
  - 線は東京式アクセントの基本の形で描いています。AquesTalk の実際の抑揚とは細かい所が違うことがあるので、最後は試聴で確かめてください
  - **線の点をつまんで上下に動かすと、その高さになるようにアクセントを置き直します**（クリックだけなら高低を入れ替え）。「ここまで高く」「ここから下げる」を、線を見ながら直接直せます
  - 「高低の線を表示」で消すこともできます
- **キーボードでアクセントを付ける**：変換結果の欄で、カーソルのある文節のアクセントを動かせます
  - Alt＋← ／ Alt＋→：前／後ろの文字へ（端まで行くと平板）　Alt＋↑：カーソルの前の文字に付ける　Alt＋↓：外す
- **ショートカットキー**：主な操作にキーを割り当て、ボタンにも（F5）のように書き添えました。設定タブで好きなキーに変えられます
  - 試聴 F5 ／ 止める F6 ／ 再チェック F7 ／ アクセント編集 F8 など（一覧は README にあります）
- **文字の大きさ**：設定タブで 80%〜200% の間で変えられるようにしました。Ctrl＋マウスホイールや Ctrl＋＋ ／ Ctrl＋－ でも変えられ、ウィンドウも同じ割合で大きくなります。高解像度のモニタでも読みやすくなります
- **［▶ 試聴］［■ 停止］を大きく**しました（よく使うので、［コピー］と同じ大きさに）
- **辞書の自動バックアップ**：起動したときと、削除・取り込み・戻すの前に、辞書を `backup` フォルダへ写します（新しい20個まで）
  - 辞書タブの **［バックアップから戻す…］** で、日時と件数を見ながら前の状態に戻せます
  - 辞書ファイルが壊れて読めないときも起動できるようにし、壊れたファイルを残して、メッセージ欄で戻し方を案内します（これまでは起動できませんでした）
- Python で動かすときにダブルクリックするファイルの名前を `yukkuri-accent.pyw` に変えました（日本語の名前だと、Windows の ZIP 展開で文字化けすることがあったため。.exe 版には関係ありません）
- FAQ に、高低の線・キーボード操作・文字の大きさ・ショートカット・バックアップの質問を足しました
