## お知らせ：「スマート アプリ コントロール」で起動できない場合
Windows 11 の PC で、`yukkuri-accent.exe` を開くと次のように表示され、起動できないことがあります。

> スマート アプリ コントロールが安全でない可能性のあるアプリをブロックしました

作者の PC でも、同じ v0.9.0 が**メインの PC では動き、サブの PC では止まる**ということが起きました。調べた結果は次のとおりです。

- **原因**：Windows 11 の保護機能「スマート アプリ コントロール」です。電子署名のない exe を止めます。いつもの「WindowsによってPCが保護されました」（「詳細情報」→「実行」で通せるもの）と違い、**実行するボタンがありません**。zip のブロックを解除（プロパティ →「許可する」）しても通りませんでした
- **PC によって違う理由**：スマート アプリ コントロールは、Windows 11 を入れた直後は「評価」モードで、使い方を見て Windows が**自動で「オン」か「オフ」に切り替えます**。作者のメインの PC は自分で設定した覚えがないまま「オフ」に、サブの PC は「オン」になっていました。いまの状態は、Windows セキュリティ →［アプリとブラウザー コントロール］→［スマート アプリ コントロールの設定］で見られます
- **解決方法：Python で動かす**。署名付きの Python で動かすので止められません。**サブの PC（オン）で、この方法で起動できることを確かめました。** 機能は exe 版とまったく同じで、辞書や設定もそのまま引き継げます
  1. [python.org](https://www.python.org/downloads/) から Python を入れる（途中の「tcl/tk and IDLE」はチェックが入ったまま）
  2. このページの Assets にある「**Source code (zip)**」をダウンロードして展開する
  3. 今まで使っていた `accent_dict.json`・`numbers.json`・`settings.json`・`backup` フォルダを、展開したフォルダへコピーする
  4. `yukkuri-accent.pyw` をダブルクリックする
- スマート アプリ コントロールをオフにする方法もありますが、**一度オフにすると Windows を入れ直さない限りオンに戻せず**、ほかのアプリへの守りも無くなるので、おすすめしません
- このツールは無料で配っているので、年に数万円かかる署名の証明書は使っていません。ご不便をおかけしますが、オンの PC では Python での起動をお願いします
