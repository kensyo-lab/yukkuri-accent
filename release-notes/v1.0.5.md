## 変更
台本の「質量6.69×10^15kg」が、`…かけ'る/じゅ'ーの/〓じょー/じゅーごきろぐ'らむ` のように、「じょー」が指数（15）より前に出ていました。もともと ×10⁶ のように指数が YMM4 で消える場合のための読み方で、指数が残っている場合を考えていなかったためです。
- 指数が次の数字タグとして残っているとき（`かける<NUMK VAL=10><NUMK VAL=15 COUNTER=きろぐらむ>`）は、`かけ'る/じゅ'ーの/じゅーごじょー/きろぐ'らむ` と、指数を読んでから「じょー」と単位を続けるようにしました。
- 前の数にアクセントがあるとき（6.69 の `ろ_クきゅ'ー` など）は、`かけ'る` の前で句を切るようにしました。これまでは `ろ_クきゅ'ーかけ'る` と1つの句にアクセントが2つになり、v1.0.3 からはエラーとしてコピーも試聴もできませんでした。前の数にアクセントが無いとき（1.3 の `さん` など）は、これまでどおりつなげて読みます。
- 指数が YMM4 で消える ×10⁶ は、これまでどおり 〓 で知らせます。
