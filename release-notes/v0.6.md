## 変更
- **文節の右クリックメニュー**：アクセント編集の欄でも、変換結果の欄でも、文節を右クリックするとその文節だけを操作できます。メニューには、戻した後の形も出ます
  - **この文節を変換直後に戻す**：アクセントを動かしすぎた・区切りを変えたら変になった、をその文節だけ一発で戻せます。区切りを足したり消したりした所も、まとめて戻ります
  - **この文節を辞書適用前に戻す**：辞書で置き換える前の、YMM4 の読みのままの形に戻します
  - **この文節を学習候補に送る**：その文節の手直しだけを学習タブの候補に送ります。手直し全体を送らなくても、直した所からすぐ辞書を育てられます
  - どれも Ctrl+Z で取り消せるので、気軽にいろいろ試せます
- **誤爆しやすい辞書の項目に印**：辞書タブに「注意（誤爆しやすい）」の列を足しました。短い語（2拍以下）・助詞だけ・「わ」を含む短い語・助詞と同じ文字で始まる／終わる短い語を橙色で表示し、「誤爆しやすい項目だけ」で絞り込めます（「句頭のみ」を付けると当たりにくくなります）
- **バックアップの比較**：［バックアップから戻す…］で、各時点に戻すと今の辞書から何件増える・消える・変わるかを表示し、選ぶと中身を一覧で確かめられます
- 他の辞書を取り込むとき、使用回数は 0 から数え、登録日は取り込んだ日にするようにしました（作者の利用記録を持ち込まないため）。同梱の作者の辞書からも、使用回数と登録日を外しました
- zip の README に、その zip の版を書き込むようにしました。入れ替え方の案内も「辞書・設定・バックアップは残し、それ以外は新しい版に置き換える」に改めています

## 入れ替え方
ユーザーデータの `accent_dict.json`（辞書）・`numbers.json`（数字の読み表）・`settings.json`（設定）・`backup` フォルダはそのまま残し、それ以外の配布ファイル（`yukkuri-accent.exe`・README・FAQ・CHANGELOG・`dictionaries` など）は、新しい版のもので置き換えてください。
